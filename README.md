# 🚀 Portafolio Profesional - Joan Sebastian Blanco Ruiz

¡Bienvenido a mi portafolio web personal! Este proyecto reúne mis principales desarrollos como estudiante de Análisis y Desarrollo de Software (ADSO), destacando soluciones web interactivas, accesibles y estructuradas con buenas prácticas.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica y accesibilidad web.
* **CSS3:** Maquetación responsive (Flexbox, Grid), variables CSS y diseño moderno.
* **JavaScript (ES6+):** Lógica del lado del cliente, manipulación del DOM y manejo de eventos.
* **FontAwesome:** Iconografía vectorial para habilidades y redes sociales.
* **FormSubmit / Formspree:** Procesamiento de envíos del formulario de contacto.
